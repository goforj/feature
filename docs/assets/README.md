# Asset sources

logo.png is an original transparent raster mascot generated with the built-in imagegen tool. logo-prompt.txt retains the prompt and sibling style-reference provenance. The generated image was copied into this repository; consumers do not depend on an agent-local path.

check.svg, rollout.svg, snapshot.svg, and refresh.svg are original repository-owned vector icons. Their labels remain separate searchable text in the README.

status.svg, unit.svg, and coverage.svg are generated by tools/maintain. Unit counts and exact library statement coverage come from the deliberately recorded docs/unit-results.json and are rejected when the relevant source fingerprint is stale. The release badge is projected from the coordinated version in internal/devtools/release.go. Exact publication and installation evidence is recorded in docs/release-readiness.md.
